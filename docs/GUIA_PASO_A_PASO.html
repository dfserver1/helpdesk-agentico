1. Qué es esto (en 30 segundos)

Un agente de soporte IT con:

  • RAG — responde usando la documentación que le des (recuperación híbrida BM25 + vectores + reranking).
  • Autoaprendizaje — cada respuesta correcta se guarda en memoria y mejora sus futuras respuestas.
  • Conectores opcionales — busca en SharePoint/Teams/Outlook (Microsoft 365) y en la web cuando no hay documentación interna.
  • Multihilo — atiende varias personas a la vez sin saturarse.
  • Tickets + SLA — clasifica (P1–P4), asigna prioridad y puede escalar a un humano.

3. Paso 1 — Descomprimir y preparar el entorno (local)

1Descomprime el zip en una carpeta, p. ej. C:\HelpDeskCopilot.
2Abre una terminal (Windows: menú Inicio → teclea powershell → Enter).
3Entra en la carpeta del proyecto:
cd C:\HelpDeskCopilot
4Ejecuta el instalador automático (crea el entorno virtual, instala dependencias y genera el archivo .env desde .env.example). Tarda 2–5 min:
python scripts/bootstrap.py

4. Paso 2 — Obtener la API key de Gemini (gratis)

  1. Entra en aistudio.google.com/apikey.
  2. Pulsa Create API key y elige o crea un proyecto.
  3. Copia la clave (empieza por AIza...).
  4. Abre el archivo .env con el bloc de notas y sustituye: 
    GOOGLE_API_KEY=PASTE_YOUR_AI_STUDIO_KEY_HERE
    por 
    GOOGLE_API_KEY=AIza...tu_clave_real
  5. Guarda y cierra.
⚠️ Nunca compartas el archivo .env. Es tu secreto.

5. Paso 3 — Crear el super-admin y arrancar en local

python scripts/seed.py        # crea el usuario admin (idempotente)
python scripts/run_api.py     # arranca la API en http://localhost:8000

Deja esa terminal abierta. Abre una segunda terminal en la misma carpeta:

python scripts/run_ui.py      # interfaz visual en http://localhost:8501

Abre el navegador en http://localhost:8501 e inicia sesión con:

CampoValor
Usuarioadmin@helpdesk.ai
Contraseñala que pusiste en ADMIN_PASSWORD del .env
Opción sin interfaz: python scripts/run_cli.py abre un chat interactivo en la terminal.

6. Paso 4 — Comprobar que funciona (prueba)

  1. Inicia sesión en la UI (http://localhost:8501).
  2. En Chat, escribe: “¿Cómo restablezco una contraseña de Windows?”
  3. Recibirás una respuesta con fuentes al final.
  4. En Self-Training → Teach the agent guarda un caso:
    • Issue: VPN no conecta en casa
    • Resolution: Registrar el equipo en AAD y resetear credenciales
  5. Pregunta de nuevo por la VPN → ahora usa la memoria aprendida.
Verificación opcional completa: python -m pytest

7. Paso 5 — Ponerlo en PRODUCCIÓN (gratis)

7.1 Subir el código a GitHub

git init
git add .
git commit -m "HelpDesk Enterprise Copilot"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/helpdesk-copilot.git
git push -u origin main
El .gitignore ya excluye .env, data/, logs/ y *.db.

7.2 Crear la base de datos en Supabase

  1. Entra a supabase.com → New project (plan Free).
  2. Ve a Project Settings → Database → Connection string → URI.
  3. Copia la URI y cambia ?sslmode=require por ?ssl=require: 
    postgresql://postgres.PROYECTO:CLAVE@aws-0-region.pooler.supabase.com:6543/postgres?ssl=require

7.3 Publicar en Hugging Face Spaces

  1. Crea un Space en huggingface.co/new-space: SDK: Docker, Hardware: CPU Basic (gratis), Name: helpdesk-copilot.
  2. En Settings → Repository secrets añade:
SecretValor
GOOGLE_API_KEYAIza... (Gemini)
JWT_SECRET_KEY32+ caracteres aleatorios
DATABASE_URLURI de Supabase (7.2)
ADMIN_EMAILadmin@helpdesk.ai
ADMIN_PASSWORDcontraseña fuerte
ENVIRONMENTproduction
LLM_PROVIDERgoogle_gemini
  1. En Settings → Connect to GitHub Repo elige tu repositorio. El Space construye y despliega solo.
  2. La API queda en https://<tu-usuario>-helpdesk-copilot.hf.space. Compruébalo añadiendo /api/v1/health en el navegador.

8. Conexión a Microsoft Copilot Studio (opcional)

  1. En Power Automate / Power Apps: Data → Custom connectors → New → Import an OpenAPI file, sube docs/copilot_studio_openapi.json.
  2. General: revisa que el host sea xxx.hf.space.
  3. Security: API Key → parámetro Authorization, ubicación Header.
  4. Test con un token obtenido de POST /api/v1/auth/login.
  5. En Copilot Studio: agente → Tools → Add a tool → Connector. Configura message como “Dynamically fill with AI”.
Guías detalladas en el proyecto: docs/DEPLOY_GOOGLE.md y docs/DEPLOY_COPILOT_STUDIO.md.

10. Solución de problemas frecuentes

SíntomaSolución
Error GOOGLE_API_KEYLa clave debe estar completa (AIza...) en .env o secrets.
Error de JWT_SECRET_KEYEn producción debe tener 32+ caracteres.
Rate limit exceeded (429)Sube RATE_LIMIT_PER_MINUTE en el entorno.
“No encontré información”Enséñale casos en Self-Training.
Space HF “App not running”Revisa los secrets del Space (el Dockerfile arranca en $PORT).
Conectores vacíosCONNECTORS_ENABLED=true + GRAPH_* válidos.
OAuth “not configured”Faltan las claves GOOGLE_OAUTH_*/MICROSOFT_OAUTH_*.

Checklist final antes de producción

  • GOOGLE_API_KEY real y probada en local.
  • .env nunca subido a GitHub (solo .env.example).
  • JWT_SECRET_KEY de 32+ caracteres en los secrets del Space.
  • DATABASE_URL de Supabase con ?ssl=require.
  • Admin probado en local antes de publicar.
  • (Opcional) Conector importado y probado en Copilot Studio.
